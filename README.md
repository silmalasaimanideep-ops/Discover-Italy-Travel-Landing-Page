# 🇮🇹 Discover Italy – Travel Landing Page

A **beautiful and responsive travel landing page** built with **pure HTML and CSS** to showcase the charm and attractions of Italy.  
Perfect for travel agencies, tourism portfolios, or personal projects!

---

## 🌐 Live Demo

🔗  https://discover-italy-travel-landing-page.pages.dev

---

## ✨ Features

- Clean and modern layout
- Static landing page
- Fully responsive design
- Built using only HTML and CSS
- Includes navigation, hero banner, content sections, and footer
- Great visuals for showcasing travel destinations

## 🖥️ How to View Locally

No installation or dependencies required — just open in a browser!

1. Clone the repository:

```bash
git clone https://github.com/silmalasaimanideep-ops/Discover-Italy-Travel-Landing-Page.git
```

2. Go into the project folder:

```bash
cd Discover-Italy-Travel-Landing-Page
```

3. Open the page in your browser:

```
Open `index.html`
```
